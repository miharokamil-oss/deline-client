## 🔐 Безопасность

```
┌─────────────────────────────────────────────────────────────────┐
│                    ПРОВЕРКА WEBHOOK                              │
└─────────────────────────────────────────────────────────────────┘

1. Xsolla отправляет webhook с заголовком:
   Authorization: Signature {signature}

2. Backend вычисляет ожидаемую подпись:
   HMAC-SHA1(request_body, webhook_secret)

3. Сравнение подписей:
   if (received_signature === expected_signature) {
     ✅ Обработать платеж
   } else {
     ❌ Отклонить запрос
   }
```

## 🔄 Состояния заказа

```
┌──────────┐
│ pending  │  ← Заказ создан, ожидает оплаты
└──────────┘
     │
     │ Пользователь оплачивает
     ▼
┌──────────┐
│completed │  ← Оплата успешна, товар выдан
└──────────┘

     или

┌──────────┐
│  failed  │  ← Оплата не прошла
└──────────┘

     или

┌──────────┐
│ refunded │  ← Возврат средств
└──────────┘
```

## 🌐 Endpoints

### Frontend → Backend:
```
POST /api/payment/create
  ↓
  Создание платежа
  ↓
  Возврат URL для оплаты

GET /api/payment/status/:orderId
  ↓
  Проверка статуса заказа
  ↓
  Возврат информации о заказе
```

### Xsolla → Backend:
```
POST /api/payment/webhook
  ↓
  Проверка подписи
  ↓
  Обновление статуса заказа
  ↓
  Выдача товара
  ↓
  Ответ 204 No Content
```

## 📊 Мониторинг

### Где смотреть логи:

1. **Backend консоль**
   - Запросы к API
   - Webhook уведомления
   - Ошибки

2. **Xsolla Publisher Account**
   - Transactions → История платежей
   - Webhooks → Логи webhook запросов

3. **Supabase**
   - Table Editor → orders
   - SQL Editor → Запросы

4. **Browser Console (F12)**
   - Network → XHR запросы
   - Console → Ошибки JS
