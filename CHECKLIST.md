## 🎯 Получение API ключей

### Merchant ID
- [ ] Открыл **Company settings** → **Company**
- [ ] Скопировал **Merchant ID**
- [ ] Вставил в `.env` → `XSOLLA_MERCHANT_ID`

### Project ID
- [ ] Открыл **Project settings**
- [ ] Скопировал **Project ID**
- [ ] Вставил в `.env` → `XSOLLA_PROJECT_ID`

### API Key
- [ ] Открыл **Company settings** → **API keys**
- [ ] Нажал **Generate API key**
- [ ] Скопировал ключ (показывается один раз!)
- [ ] Вставил в `.env` → `XSOLLA_API_KEY`

### Webhook Secret
- [ ] Открыл **Project settings** → **Webhooks**
- [ ] Включил webhooks
- [ ] Скопировал **Webhook secret key**
- [ ] Вставил в `.env` → `XSOLLA_WEBHOOK_SECRET`
