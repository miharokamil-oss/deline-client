# 🎓 GITHUB ДЛЯ ЧАЙНИКОВ - Пошагово с картинками (в уме)

## 🤔 ЧТО ТАКОЕ GITHUB? (простыми словами)

Представь что GitHub - это как Google Drive, но для кода.

- **Google Drive** - хранит документы, фотки
- **GitHub** - хранит код твоего сайта

**Зачем это нужно?**
Render.com (где будет работать твой backend) умеет брать код только из GitHub. Поэтому нужно сначала загрузить код туда.

---

## 📋 ШАГ 1: УСТАНОВКА GIT (5 минут)

### Что такое Git?
Git - это программа которая помогает загружать код на GitHub. Как проводник Windows, но для кода.

### Что делать:

1. **Скачай Git:**
   - Открой браузер
   - Перейди на: [https://git-scm.com/download/win](https://git-scm.com/download/win)
   - Скачается файл типа `Git-2.43.0-64-bit.exe`

2. **Установи Git:**
   - Запусти скачанный файл
   - Появится окно установки
   - **ПРОСТО НАЖИМАЙ "NEXT" (Далее) ВЕЗДЕ!**
   - Не меняй никакие настройки
   - В конце нажми "Finish" (Готово)

3. **Перезагрузи компьютер:**
   - Это важно! Git заработает только после перезагрузки

4. **Проверь что установилось:**
   - Открой папку с твоим проектом
   - Нажми правой кнопкой мыши на пустом месте
   - Должен появиться пункт **"Git Bash Here"**
   - Если есть - отлично! ✅
   - Если нет - перезагрузи еще раз

## 📋 ШАГ 2: РЕГИСТРАЦИЯ НА GITHUB (3 минуты)

### Что делать:

1. **Открой GitHub:**
   - Перейди на: [https://github.com/signup](https://github.com/signup)

2. **Введи email:**
   - Введи свой email
   - Нажми "Continue" (Продолжить)

3. **Придумай пароль:**
   - Придумай надежный пароль
   - Нажми "Continue"

4. **Придумай username:**
   - Это будет твое имя на GitHub
   - Например: `zenex-developer`
   - Нажми "Continue"

5. **Подтверди что ты не робот:**
   - Реши капчу (выбери картинки)
   - Нажми "Create account" (Создать аккаунт)

6. **Подтверди email:**
   - Открой свою почту
   - Найди письмо от GitHub
   - Введи код из письма на сайте

✅ Готово! Теперь у тебя есть аккаунт на GitHub.

## 📋 ШАГ 3: СОЗДАНИЕ РЕПОЗИТОРИЯ (2 минуты)

### Что такое репозиторий?
Репозиторий - это как папка на GitHub, где будет храниться твой код.

### Что делать:

1. **Войди на GitHub:**
   - Перейди на: [https://github.com/](https://github.com/)
   - Введи свой email и пароль
   - Нажми "Sign in" (Войти)

2. **Создай новый репозиторий:**
   - Слева вверху найди зеленую кнопку **"New"** (Новый)
   - Нажми на нее

3. **Заполни информацию:**
   
   **Repository name** (Название репозитория):
   ```
   zenex-client
   ```
   
   **Description** (Описание) - необязательно:
   ```
   Zenex Client Website
   ```
   
   **Public или Private:**
   - Выбери **Public** (Публичный)
   - Это бесплатно и нужно для Render.com
   
   **НЕ СТАВЬ ГАЛОЧКИ!**
   - Не ставь галочку "Add a README file"
   - Не выбирай .gitignore
   - Не выбирай license

4. **Создай:**
   - Нажми зеленую кнопку **"Create repository"** (Создать репозиторий)

5. **Скопируй URL:**
   - Появится страница с инструкциями
   - Найди строку типа:
   ```
   https://github.com/твой-username/zenex-client.git
   ```
   - Скопируй ее (Ctrl+C)
   - Вставь в блокнот, подпиши "GitHub URL"

✅ Готово! Репозиторий создан, но пока пустой.

## 📋 ШАГ 4: ЗАГРУЗКА КОДА НА GITHUB (5 минут)

### Что будем делать:
Сейчас загрузим весь твой код (все файлы проекта) на GitHub.

### Что делать:

1. **Открой папку с проектом:**
   - Открой проводник Windows
   - Найди папку где лежит твой проект
   - Это папка где есть файлы: index.html, shop.html, папка backend и т.д.

2. **Открой Git Bash:**
   - Нажми правой кнопкой мыши на пустом месте в папке
   - Выбери **"Git Bash Here"**
   - Откроется черное окно с текстом

3. **Скопируй и вставь команды:**
   
   **ВАЖНО! Вставляй команды ПО ОДНОЙ!**
   
   **Команда 1:** Инициализация Git
   ```bash
   git init
   ```
   - Скопируй эту строку
   - Вставь в Git Bash (правой кнопкой → Paste или Shift+Insert)
   - Нажми Enter
   - Должно написать: "Initialized empty Git repository"
   
   **Команда 2:** Добавление всех файлов
   ```bash
   git add .
   ```
   - Скопируй эту строку
   - Вставь в Git Bash
   - Нажми Enter
   - Ничего не напишет - это нормально
   
   **Команда 3:** Создание коммита
   ```bash
   git commit -m "Initial commit"
   ```
   - Скопируй эту строку
   - Вставь в Git Bash
   - Нажми Enter
   - Напишет сколько файлов добавлено
   
   **Команда 4:** Создание ветки main
   ```bash
   git branch -M main
   ```
   - Скопируй эту строку
   - Вставь в Git Bash
   - Нажми Enter
   
   **Команда 5:** Подключение к GitHub
   ```bash
   git remote add origin https://github.com/твой-username/zenex-client.git
   ```
   - **ВАЖНО!** Замени `твой-username` на свой username из GitHub!
   - Например: `git remote add origin https://github.com/zenex-developer/zenex-client.git`
   - Скопируй СВОЮ строку
   - Вставь в Git Bash
   - Нажми Enter
   
   **Команда 6:** Загрузка на GitHub
   ```bash
   git push -u origin main
   ```
   - Скопируй эту строку
   - Вставь в Git Bash
   - Нажми Enter
   - **Появится окно входа в GitHub!**

4. **Войди в GitHub:**
   - Появится окно браузера
   - Нажми "Authorize Git Credential Manager" (Разрешить)
   - Или введи свой email и пароль от GitHub
   - Закрой окно браузера

5. **Подожди:**
   - В Git Bash пойдет загрузка
   - Будет написано: "Uploading objects: 100%"
   - Подожди пока закончится (1-2 минуты)

6. **Проверь:**
   - Открой браузер
   - Перейди на: `https://github.com/твой-username/zenex-client`
   - Должны появиться все твои файлы!
   - Если видишь файлы - отлично! ✅

✅ Готово! Код загружен на GitHub!

## 🐛 ЧТО ДЕЛАТЬ ЕСЛИ ОШИБКА?

### Ошибка: "git: command not found"

**Причина:** Git не установлен или не перезагрузил компьютер

**Решение:**
1. Перезагрузи компьютер
2. Попробуй снова
3. Если не помогло - переустанови Git

### Ошибка: "Permission denied"

**Причина:** Нет доступа к GitHub

**Решение:**
1. Проверь что вошел в GitHub в браузере
2. Попробуй команду `git push` еще раз
3. Должно появиться окно входа

### Ошибка: "fatal: remote origin already exists"

**Причина:** Уже подключался к GitHub

**Решение:**
1. Пропусти команду `git remote add origin`
2. Сразу выполни `git push -u origin main`

### Ошибка: "Updates were rejected"

**Причина:** На GitHub уже есть файлы

**Решение:**
1. Выполни команду:
   ```bash
   git push -u origin main --force
   ```
2. Это перезапишет все на GitHub
