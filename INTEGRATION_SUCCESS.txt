🚀 ЧТО НУЖНО СДЕЛАТЬ:

1. Зарегистрируйся в Xsolla (2 минуты)
   👉 https://publisher.xsolla.com/signup

2. Получи API ключи (2 минуты)
   - Merchant ID
   - Project ID
   - API Key
   - Webhook Secret

3. Заполни backend/.env (1 минута)
   Вставь свои ключи в файл

4. Проверь настройку (10 секунд)
   cd backend
   npm run check

5. Запусти backend (30 секунд)
   npm start

6. Запусти ngrok (30 секунд)
   ngrok http 3000

7. Настрой webhook в Xsolla (30 секунд)
   Вставь URL: https://xxxx.ngrok.io/api/payment/webhook

8. Тестируй! (1 минута)
   Открой сайт → Магазин → Купить → Оплатить
   Карта: 4111 1111 1111 1111
