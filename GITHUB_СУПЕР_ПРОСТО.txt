🤔 ЧТО ТАКОЕ GITHUB?

GitHub = Google Drive для кода

Твой компьютер → GitHub → Render.com
     (код)      (хранит)   (запускает)

═══════════════════════════════════════════════════════════════════

📥 ШАГ 1: УСТАНОВИ GIT (5 минут)

1. Открой: https://git-scm.com/download/win
2. Скачай файл (Git-xxx.exe)
3. Запусти файл
4. Нажимай "Next" везде (ничего не меняй!)
5. Нажми "Finish"
6. ПЕРЕЗАГРУЗИ КОМПЬЮТЕР! (обязательно!)

Проверка:
- Открой папку с проектом
- Правая кнопка мыши → должен быть "Git Bash Here"
- Если есть - ОК! ✅

═══════════════════════════════════════════════════════════════════

👤 ШАГ 2: СОЗДАЙ АККАУНТ НА GITHUB (3 минуты)

1. Открой: https://github.com/signup
2. Введи email → Continue
3. Придумай пароль → Continue
4. Придумай username (например: zenex-dev) → Continue
5. Реши капчу
6. Create account
7. Открой почту → введи код из письма

Запомни свой username! Он понадобится!

═══════════════════════════════════════════════════════════════════

📁 ШАГ 3: СОЗДАЙ РЕПОЗИТОРИЙ (2 минуты)

1. Войди на: https://github.com/
2. Нажми зеленую кнопку "New" (слева вверху)
3. Repository name: zenex-client
4. Выбери: Public
5. НЕ СТАВЬ НИКАКИЕ ГАЛОЧКИ!
6. Нажми "Create repository"
7. Скопируй URL (типа: https://github.com/твой-username/zenex-client.git)

═══════════════════════════════════════════════════════════════════

⬆️ ШАГ 4: ЗАГРУЗИ КОД (5 минут)

1. Открой папку с проектом (где index.html, shop.html и т.д.)
2. Правая кнопка мыши → "Git Bash Here"
3. Откроется черное окно

ВСТАВЛЯЙ КОМАНДЫ ПО ОДНОЙ! (правая кнопка → Paste)

Команда 1:
git init
[Enter]

Команда 2:
git add .
[Enter]

Команда 3:
git commit -m "Initial commit"
[Enter]

Команда 4:
git branch -M main
[Enter]

Команда 5 (ЗАМЕНИ твой-username на свой!):
git remote add origin https://github.com/твой-username/zenex-client.git
[Enter]

Команда 6:
git push -u origin main
[Enter]

Появится окно входа → войди в GitHub

Подожди 1-2 минуты пока загрузится

═══════════════════════════════════════════════════════════════════

✅ ПРОВЕРКА

Открой: https://github.com/твой-username/zenex-client

Видишь свои файлы? → ВСЕ ГОТОВО! 🎉

🐛 ЧАСТЫЕ ОШИБКИ

"git: command not found"
→ Перезагрузи компьютер и попробуй снова

"Permission denied"
→ Войди в GitHub в браузере и попробуй снова

"remote origin already exists"
→ Пропусти команду 5, сразу выполни команду 6
